Warden — macOS Process Manager

  • Warden is a macOS CLI tool used to give users a fast terminal alternative to the Activity Monitor for managing and terminating processes, using low-level system APIs (libproc) to scan and group running processes by parent application
  • Includes a live search mode using a min-heap to sort filtered process groups by case-insensitive sub-string matching
  • Configured build system using CMake, validated core logic with unit tests via GoogleTest, and setup installation via Homebrew tap
